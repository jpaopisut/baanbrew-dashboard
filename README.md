# บ้านบรู Dashboard

Lab 1 · Basic Data Analytics & Visualization using AI Vibe Coding

Dashboard ยอดขายของเครือร้านกาแฟ "บ้านบรู" (ข้อมูลสมมติ) 5 สาขาในกรุงเทพฯ ช่วง 1 เม.ย. 2025 – 20 ก.ย. 2026
สร้างด้วย React 19, Vite 7, Tailwind CSS 4, Recharts 3 และ PapaParse

## สิ่งที่มีใน Dashboard

- **KPI cards 4 ใบ:** ยอดขายรวม, จำนวนบิล, ยอดเฉลี่ยต่อบิล, จำนวนลูกค้าสมาชิกที่ไม่ซ้ำ (บนมือถือเรียง 2 คอลัมน์)
- **กราฟเส้นยอดขายรายวัน:** เส้นรายวันแบบจาง ทับด้วยค่าเฉลี่ย 7 วัน แกน X เป็นวันที่ภาษาไทย เช่น 1 เม.ย. 68
- **กราฟแท่งยอดขายแยกสาขา:** เรียงจากมากไปน้อย
- **กราฟจำนวนบิลตามชั่วโมงของวัน (การบ้าน):** แยกตามสาขา

## วิธีรัน

ต้องมี Node.js เวอร์ชัน 20 ขึ้นไป

```bash
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

## นิยามตัวเลข

Logic คำนวณทั้งหมดอยู่ใน [`src/lib/metrics.js`](src/lib/metrics.js)

- **ยอดขาย** = `qty × unit_price` (แปลงเป็น Number ก่อนคำนวณ)
- **จำนวนบิล** = จำนวน `order_id` ที่ไม่ซ้ำ ไม่ใช่จำนวนแถว
- **ยอดเฉลี่ยต่อบิล** = ยอดขายรวม ÷ จำนวนบิล
- **ลูกค้าสมาชิก** = จำนวน `customer_id` ที่ไม่ซ้ำ (ช่องว่าง = ลูกค้าทั่วไป ไม่นับ)
- **วันที่** = 10 ตัวอักษรแรกของ `datetime` (เวลาไทย) ไม่ใช้ `toISOString()` เพื่อไม่ให้วันเลื่อนไปตามเวลา UTC

## ข้อสังเกตจากกราฟจำนวนบิลตามชั่วโมง

## Lab 2.1 · ทำความสะอาดข้อมูลยอดขาย

Notebook: [`notebooks/Lab2_1_Data_Cleaning.ipynb`](notebooks/Lab2_1_Data_Cleaning.ipynb) · log: [`notebooks/cleaning_log.csv`](notebooks/cleaning_log.csv)

`sales_raw.csv` (53,357 แถว) → `sales_clean.csv` (53,057 แถว) ผ่าน `validate()` ทุกข้อ

| ปัญหา | จำนวน | จัดการ |
|---|---|---|
| แถวซ้ำทุกคอลัมน์ | 265 | ลบ |
| datetime ปี พ.ศ. / DD/MM/YYYY | 1,162 | แปลงเป็น `YYYY-MM-DDTHH:MM:SS+07:00` ด้วย regex (ไม่ใช้ `pd.to_datetime` กันวันกับเดือนสลับ) |
| ชื่อสาขาไม่มาตรฐาน | 1,071 | strip แล้ว map เป็น 5 ชื่อ (“ม.” = มหาวิทยาลัย) |
| ราคามีคำว่า “บาท” | 61 | ตัดคำแล้วแปลงเป็นตัวเลข |
| ราคาติดลบ | 25 | แปลงเป็นบวก (ไม่มีการคืนเงินในระบบ POS) |
| qty = 0 (บิลยกเลิก) / product_id ว่าง | 20 / 15 | ลบ |

หลังทำความสะอาด ยอดขายรวมเป็น **฿4,463,443** (34,773 บิล) ลดลงจาก Lab 1 ฿3,378 เพราะตัดแถว qty = 0 และ product_id ว่างออก

## การบ้านที่ 2 · Data Profiling ข้อมูลลูกค้า

Notebook (Colab): [`notebooks/HW2_Customer_Profiling.ipynb`](notebooks/HW2_Customer_Profiling.ipynb) · รายงาน: [`notebooks/customers_profiling_report.csv`](notebooks/customers_profiling_report.csv)

ข้อมูลสะอาดในเชิงโครงสร้าง (ไม่มีค่าว่าง ไม่มีแถวซ้ำ รูปแบบถูกต้อง) แต่พบความผิดปกติเชิงธุรกิจ:

- เบอร์โทรที่ปิดบังแล้วซ้ำกัน 99 แถว (49 เบอร์) แต่เป็นคนละคน จึงห้ามใช้เบอร์เป็น key
- สมาชิก 493 คน (16.4%) ไม่เคยซื้อเลย
- ผู้เยาว์อายุต่ำกว่า 18 มี 113 คน ต้องมีความยินยอมจากผู้ปกครองตาม PDPA
- ชื่อเล่นไม่สอดคล้องกับเพศ 707 คน ไม่แก้ เพราะไม่ควรเดาเพศจากชื่อ

ไฟล์ `customers_clean.csv` ตัด `phone` และ `nickname` ออก (Data Minimization) แล้วเพิ่ม `has_purchase`, `is_minor`, `orders`, `revenue` และ `recency_days` เพื่อใช้ในแท็บ **ลูกค้า** ซึ่งแสดง KPI สมาชิก สมาชิกใหม่รายเดือน ช่วงอายุ จำนวนครั้งที่ซื้อ สถานะตามการซื้อล่าสุด และสมาชิกต่อสาขา
