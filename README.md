# บ้านบรู Dashboard

Lab 1 · Basic Data Analytics & Visualization using AI Vibe Coding

Dashboard ยอดขายของเครือร้านกาแฟ "บ้านบรู" (ข้อมูลสมมติ) 5 สาขาในกรุงเทพฯ ช่วง 1 เม.ย. 2025 – 20 ก.ย. 2026
สร้างด้วย React 19, Vite 7, Tailwind CSS 4, Recharts 3 และ PapaParse

## สิ่งที่มีใน Dashboard

- **KPI cards 4 ใบ:** ยอดขายรวม, จำนวนบิล, ยอดเฉลี่ยต่อบิล, จำนวนลูกค้าสมาชิกที่ไม่ซ้ำ (บนมือถือเรียง 2 คอลัมน์)
- **กราฟเส้นยอดขายรายวัน:** เส้นรายวันแบบจาง ทับด้วยค่าเฉลี่ย 7 วัน แกน X เป็นวันที่ภาษาไทย เช่น 1 เม.ย. 68
- **กราฟแท่งยอดขายแยกสาขา:** เรียงจากมากไปน้อย
- **กราฟจำนวนบิลตามชั่วโมงของวัน (การบ้าน):** แยกตามสาขา

## วิธีรัน

ต้องมี Node.js เวอร์ชัน 20 ขึ้นไป

```bash
npm install
npm run dev
```

แล้วเปิด http://localhost:5173

## นิยามตัวเลข

Logic คำนวณทั้งหมดอยู่ใน [`src/lib/metrics.js`](src/lib/metrics.js)

- **ยอดขาย** = `qty × unit_price` (แปลงเป็น Number ก่อนคำนวณ)
- **จำนวนบิล** = จำนวน `order_id` ที่ไม่ซ้ำ ไม่ใช่จำนวนแถว
- **ยอดเฉลี่ยต่อบิล** = ยอดขายรวม ÷ จำนวนบิล
- **ลูกค้าสมาชิก** = จำนวน `customer_id` ที่ไม่ซ้ำ (ช่องว่าง = ลูกค้าทั่วไป ไม่นับ)
- **วันที่** = 10 ตัวอักษรแรกของ `datetime` (เวลาไทย) ไม่ใช้ `toISOString()` เพื่อไม่ให้วันเลื่อนไปตามเวลา UTC

## ข้อสังเกตจากกราฟจำนวนบิลตามชั่วโมง

1. **ช่วงพีคคือ 12:00 น.** มีทั้งหมด 3,741 บิล มากที่สุดของวัน และทุกสาขาคึกคักในช่วงนี้
2. **สีลม (ออฟฟิศ) ขายดีช่วงเช้า** สูงสุดตอน 08:00 น. (1,243 บิล) แล้วลดลงมากหลัง 17:00 น. ส่วนสยามกับบางนาขายดีช่วงบ่ายถึงเย็น (15:00–17:00 น.) และยังมีลูกค้าจนถึงค่ำ
3. **มหาวิทยาลัยมีสองช่วงพีค** คือเช้า 08:00–09:00 น. กับกลางวัน 12:00 น. แล้วแทบไม่มีลูกค้าหลังเลิกเรียน (20:00 น. เหลือ 61 บิล) ส่วนอารีย์มียอดน้อยที่สุดเพราะเพิ่งเปิดเมื่อ 1 พ.ย. 2025
